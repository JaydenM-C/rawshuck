🦪 Rawshuck

Cull RAW+JPEG shoots before importing into your photo library. Review each photo once and pick its fate: keep image+RAW, keep the image only, or delete. Runs entirely in your browser — nothing is uploaded anywhere.

README · blog

Drag & drop a folder (or image files) here

⚠ Web-version deletions are permanent — the browser cannot use the Trash. Keep your memory card (or exported originals) until you've verified the result. Prefer recoverable deletes? Use the Python version, which moves files to the macOS Trash.

This browser doesn't support local file access. Rawshuck's web version needs a Chromium browser (Chrome, Edge, Brave, Arc, Opera) — or use the Python version, which works everywhere.
